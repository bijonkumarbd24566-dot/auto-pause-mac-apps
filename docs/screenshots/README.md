Images referenced by the main [README](../../README.md). Captured on a 16 GB M1 MacBook Pro
running macOS 26.

| File | Shows |
|---|---|
| `main-panel.png` | The full menu bar panel: four frozen apps pinned at the top, running apps sorted by resident RAM with live sparklines, and the freeze-only Background Services section (bun, node, system daemons). Header reads "7 suspended / 12.47 GB of 16 GB used". |
| `free-up-memory.png` | The Free Up Memory dialog with an 8 GB target and the honest warning that only ~7.42 GB is currently available to free. |

| `frozen-app.png` | TextEdit frozen at 22.9 MB in RAM of 58.8 MB total, with the Resume action. |
